# Job Application & Placement Tracker

A web application built with Python and Flask to manage job applications and track placement progress.

## Features
- Add, edit, and delete job applications
- Search and filter applications
- Track interview dates
- View dashboard statistics and charts
- Export application data to CSV

## Technologies
- Python
- Flask
- SQLite
- HTML, CSS, JavaScript
- Chart.js

## Run Locally

1. Create a virtual environment:
   python -m venv venv

2. Activate it:
   .\venv\Scripts\Activate.ps1

3. Install Flask:
   python -m pip install flask

4. Run the app:
   python app.py

5. Open http://127.0.0.1:5000 in your browser.

## Run Tests
python -m unittest discover -v
